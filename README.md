Entry for the make.fun bounty [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61): a one-star review of Monday written as if Monday were a restaurant, in 25 words or fewer. The program writes the single review line to `entry.txt` in the output directory. The diner is seated at 6am, the waiter brings traffic, three meetings and a cold coffee that was never ordered — and the bill comes to the customer's whole weekend.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
